# GoldMate structure

- `/` — premium landing page
- `/market` — public jewelry marketplace
- `/rates` — automatic gold rate center + calculator
- `/product/[id]` — product details + order request
- `/brand/[id]` — public seller brand profile
- `/profile` — customer account, photo, details, orders
- `/seller/apply` — seller application
- `/seller` — approved seller dashboard
- `/seller/brand` — seller brand profile editor
- `/seller/new` — product publisher
- `/finance` — seller/admin finance ledger
- `/admin` — seller approvals + rate spread settings + users
- `/vip` — private admin family vault with email sharing
